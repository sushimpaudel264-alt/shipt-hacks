# CodeLingo: instructions for AI coding agents

- **Building UI (pages/components)?** Read [FRONTEND_GUIDE.md](FRONTEND_GUIDE.md) first and follow its rules:
  - get all data through `@/lib/hooks`;
  - take types from `@/lib/types`;
  - never write `fetch()` calls or new data types;
  - never edit `app/api/**` or `lib/**`.
- **Working on the API or data layer?** Read [BACKEND.md](BACKEND.md). Every route in `app/api` follows the pattern documented in `lib/server/http.ts`.
- **Before finishing:** run `npm run typecheck`, `npm run lint`, `npm test` and `npm run build`; all must pass.
